# Achive — arXiv Homepage Visual Clone

A static front-end recreation based on the supplied screenshot of the arXiv subject browse homepage.

Open `index.html` in a browser, or deploy the repository to Vercel as a static site.

The category and search links go to the official arXiv website. This is not an arXiv submission service and is not affiliated with arXiv.

The logo uses the official arXiv SVG URL provided by the user; internet access is required to display it.
